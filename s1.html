Part three
Three layers.
The most expensive mistake of the year is using the wrong one.
Three layers

1. Automation

Rules. No intelligence.
Cheap, exact, auditable.
The same input always gives the same output.

2. Automation with AI

The same fixed flow, with intelligence at the steps that read, classify or draft.
You still decide the path.

3. Agents

Intelligence decides the next step.
Powerful, metered, and never twice the same.

The rule
If there is a deterministic way to do it, do it that way.
Use an agent only where judgement is needed at every step.
Forcing generative AI into a process a rule could run makes it slower, dearer and less reliable. Not everything is an agent.
